## Redis 的 SCAN 使用注意事项和面试题讲解

## 22-2 购物车数量增减及删除
为 `ShoppingCartAppservice` 中的 `UpdateCartSelected` 方法添加之前没有制作的 增加/减少 购物车数量的功能

在前端界面中 为购物车的**增加删除**功能绑定 `UpdateCartSelected` 接口

为 `HashWorker` 添加 `RemoveKey` 根据传入的 Key 删除字段

## 22-3 Redis热数据缓存
修改 `UpdateCartSelected` 不使用原先的根据 `Context.Attach(cart);` 和 ` Context.Entry(cart).Property(m => m.CartSelected).IsModified = true;` 来定向更新字段的逻辑，而是直接从 Redis 里读取并覆盖，传入的购物车数量小于等于0时删除数据

## 22-4 缓存击穿解决方案 
修改获取 购物车数据 `GetShoppingCartDtos` ，定向更新数据库字段的逻辑，改为统一从 Redis 里获取数据，如果Redis中没有则从数据库中获取并在 Redis 中存一份。

在原先根据ProductNo寻找product的逻辑里，存在缓存击穿的可能，在这里使用lock和双if的方案来防止缓存击穿

ProductDto 中的两个**复杂类型**由于无法存到 Redis 中，于是这里创建一个 ProductCto，代表专门用于存入 Redis 中的数据，并在 `AutoMapper` 中添加转换规则，在转换时将会这两个负责类型序列化成 `Json`

```
    //将 ProductDto 中的引用类型在向Cto转换时 序列化成json
    CreateMap<ProductDto, ProductCto>().ForMember(cto => cto.ProductPhoto, dto => dto.MapFrom(dto => JsonConvert.SerializeObject(dto.ProductPhoto))).ForMember(cto => cto.ProductSale, dto => dto.MapFrom(dto => JsonConvert.SerializeObject(dto.ProductSale)));
    //CTO 转 DTO
    CreateMap<ProductCto, ProductDto>().ForMember(cto => cto.ProductPhoto, dto => dto.MapFrom(dto => JsonConvert.DeserializeObject<ProductPhoto>(dto.ProductPhoto))).ForMember(cto => cto.ProductSale, dto => dto.MapFrom(dto => JsonConvert.DeserializeObject<ProductSale>(dto.ProductSale)));
```

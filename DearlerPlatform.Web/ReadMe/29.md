## 29-2 项目收尾 解决修改物品列表 添加购物车数据不变的问题

由于获取购物车数据的操作是在 Main 界面里才发生的，如果上来进入到 ProductList 界面里，不能及时获取数据，这里把 Main 界面的 onGetCartNum 给他挪挪位置，放到 LayoutMain 里，同时在 ProductList 里引入Vuex

挪动的代码块：
```
const onGetCartNum = async () => {
    // var cno = localStorage["cno"];
    // ShoppingCartNum.value = await GetCartNum(cno)

    let cartNo = await GetCartNum();
    store.dispatch("shoppingCart/setCartNum", cartNo);
};
onMounted(async () => {
    await onGetCartNum();
});
```

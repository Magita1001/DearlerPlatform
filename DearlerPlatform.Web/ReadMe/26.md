## 26-1 一段安装 Element Plus 的玄学之旅(?)

### 使用：
从 npm 导入包之后，在 main.ts 里链式调用一下，再引入两个依赖
`use(ElementPlus)`

```
import ElementPlus from 'element-plus'

import 'element-plus/dist/index.css'
```

### 重要排坑：有时在main.ts中引入项目时，以本次的 ElementPlus 为例

```
import ElementPlus from 'element-plus'

import 'element-plus/dist/index.css'
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

createApp(App).use(router).use(store).use(ElementPlus).mount('#app')
```

在引入时会遇到引入Css那行时报出以下错误的问题。

> 找不到“element-plus/dist/index.css”的副作用导入的模块或类型声明。 

#### 错误原因：
- TypeScript 不知道 *.css 可以被当成模块导入
- 这个项目之前没有把声明文件正确纳入 TypeScript 编译范围
- 于是编辑器/编译器会报：“找不到模块或其对应的类型声明”

#### 解决方案：

首先检查 `tsconfig.json` 里的 `include` ，查看其是否有类似 `"src/**/*.d.ts"` 的声明，没有就补上。

让 ts 正确检查声明文件。

- Cli项目的解决方案
    - 为项目中的 `.d.ts` 文件内添加以下声明
    ```
    declare module '*.css' {
    const content: Record<string, string>
    export default content
    }

    declare module '*.scss' {
    const content: Record<string, string>
    export default content
    }
    ```

- Vite项目的解决方案
    - 检查项目中是否有 `.d.ts` 文件，没有则新建，名称一般为 `vite-env.d.ts`
    - 写入 `/// <reference types="vite/client" />`
    - 它的作用是让 TS 知道 Vite 的类型和 CSS 模块声明。

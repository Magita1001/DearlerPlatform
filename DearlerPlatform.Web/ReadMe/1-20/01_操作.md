### Program配置：
配置DbContext，配置swagger调试，注册IRepository泛型类
```
        //依赖注入区
        var GetConnectionString = builder.Configuration.GetConnectionString("Default");
        builder.Services.AddDbContext<DealerPlatformContext>(opt =>
        {
            opt.UseSqlServer(GetConnectionString);
        });
        //注入泛型类的方式
        builder.Services.AddTransient(typeof(IRepository<>), typeof(Repository<>));

             if (app.Environment.IsDevelopment())
        {
            app.MapOpenApi();
            app.UseSwaggerUI(opt =>
            {
                opt.SwaggerEndpoint("/openapi/v1.json", "v1.json");
            });

            //使用微软的api测试工具
            // app.MapScalarApiReference();
        }
```

### 编写Repository类 用于查询数据，编写四个方法用于查询，这里标出`GetListAsync`：
```
    public async Task<List<TEntity>> GetListAsync(Func<TEntity, bool> predicate)
    {
        var dbSet = _dbContext.Set<TEntity>();
        return await dbSet.Where(predicate).AsQueryable.ToListAsync();
    } 
```

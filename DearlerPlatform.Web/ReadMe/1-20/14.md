## 14-2 
对添加购物车修改，相同的物品添加到购物车时，不添加新物品，而是在原有物品上对`ProductNum + 1`

在修改数据时，在 `ShoppingCartAppservice` 的 `UpdateAsync`这个方法中，会遇到
> 最里面的异常 Microsoft.Data.SqlClient.SqlException : 无法更新标识列 'Id'。

这个报错，原因是EfCore在修改数据时会将除主键外的所有数据标记为已修改，但是sql不允许对自增标识列(ID)有任何修改，即使赋的值和原值一样也不行

此时可以在 DbSet 文件中，找到 ShoppingCart的Id字段，在后面添加

> .Metadata.SetAfterSaveBehavior(Microsoft.EntityFrameworkCore.Metadata.PropertySaveBehavior.Ignore);

作用为：告诉 EF Core：保存后（更新时），绝对忽略对该属性的任何修改！

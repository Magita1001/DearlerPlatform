## 7-2 排序分页封装
Core层中创建一个 `PageWithSortDto` ，用来传输 排序规则 分页数据 等信息

将除了 `Controller` 中的其他所有需要

> ProductDtoAsync(string? sort, int pageIndex = 1, int pageSize = 30)

参数的地方，替换为 `PageWithSortDto`

引用了ace提供的 字符串排序包 ，提供了拓展方法，可以在OrderBy系列方法中直接填入字符串，用来作为键，如：
> return await dbSet.OrderBy(m => pageWithSortDto.Sort).Skip(skip).Take(pageWithSortDto.PageSize).ToListAsync();
> return await dbSet.OrderBy(pageWithSortDto.Sort).Skip(skip).Take(pageWithSortDto.PageSize).ToListAsync();

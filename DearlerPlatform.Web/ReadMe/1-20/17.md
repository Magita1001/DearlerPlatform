创建 store.ts，进行以下配置

```

export default createStore({
    state: {
        
    },

    },
    mutations: {
        
    },

    },

    }

```

### 各个属性的作用：
1. `state` —— 全局数据源（相当于组件的 data）
- **作用**：存放应用中所有需要共享的原始数据。

- **特点**：里面的数据是响应式的，只要数据改变，所有使用了该数据的视图组件都会自动重绘。

- **规则**：只能读取，绝不能在组件中直接手动给它赋值修改（例如 store.state.count = 1 是危险且不规范的操作）。

2. `getters` —— 派生计算属性（相当于组件的 computed）
- **作用**：基于 state 中的基础数据，派生/计算出新的数据。

- **特点**：自带缓存机制。只要它依赖的 state 没有变化，多次读取会直接返回之前的缓存结果，性能极高。

- **参数**：默认接收 state 作为第一个参数。

3. `mutations` —— 同步状态修改器（修改 State 的唯一合法途径）
- **作用**：专门且唯一用来修改 state 中数据的函数集合。

- **特点**：必须是纯同步函数！ 严禁在 mutations 里写任何 setTimeout、async/await 或 Axios 网络请求，否则 Vue DevTools 开发者工具将无法追踪数据变化的前后快照。  

- **调用方式**：在组件或 Action 中通过 store.commit('mutation名称', 参数) 来触发。

4. `actions` —— 异步业务逻辑处理器（相当于组件的 methods）
- **作用**：处理所有异步操作（如调用后端 API 接口、定时器）以及复杂的业务逻辑判定。

- **特点**：Action 不能直接修改 state，它必须在处理完异步任务后，调用 context.commit('MUTATION_NAME') 交给 mutation 去修改数据。

**调用方式**：在组件中通过 store.dispatch('action名称', 参数) 来触发。

5. `modules` —— 子模块拆分（防止单一 Store 过于臃肿）
- **作用**：当项目极其庞大时，将全局 Store 按照业务板块拆分成多个独立的“子 Store”（如用户模块、商品模块、购物车模块）。

- **特点**：每个子模块都可以拥有自己独立的 `state`, `getters`, `mutations`, `actions`，甚至继续嵌套子模块。

关于modules的用法，他的子模块的写法和结构，以及用法和在createStore中的store一模一样，区别在于在子模块中，建议加入namespaced属性，就像下面这样

```
modules: {
        shoppingCart: {
            namespaced: true,
            state: {
                cartNum: 10
            },
            getters: {
                getCartNum(state) {
                    return state.cartNum
                }
            },
            mutations: {
                setCartNum(state, num) {
                    state.cartNum = num
                },
            },
            actions: {
                setCartNum(context, num) {
                    context.commit("setCartNum", num)
                },
            },
        }
    },
```

这么做是为了防止模块之间的方法重名问题，使用时只需要像这样对照修改
- `store.dispatch("setCartNum", currentCartNum) `→ `store.dispatch("shoppingCart/setCartNum", currentCartNum)`

- `{{ store.getters.getCartNum }}` → `{{ store.getters["shoppingCart/getCartNum"] }}`
